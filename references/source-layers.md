# 资料分层与优先级

这份文件定义：一份资料进来时怎么归类、归错时怎么裁决、缺什么时怎么降级。它是主循环第 1 步的执行契约，不依赖具体学科。

## 1. 为什么不是一条优先级链

把「教材 > 教辅 > 考纲 > 其他」压成一条链，会在三种场景里失效：

- 教材讲了一个考纲不要求的方法，按链要讲，实际应该跳过；
- 国外教材的定义比国内教材严谨，按链要听国内的，实际应该按严谨的讲、按国内的写；
- 考纲写"掌握极限计算"，真题只考等价无穷小，按链会平均用力，实际应该按真题倾斜。

所以拆成三层，每层只裁决一件事：范围层管边界，权威层管正确性，应试层管考法。

## 2. 四标 schema

每份资料入库时写一条 `records/sources.jsonl`：

```json
{
  "id": "DOC-0003",
  "title": "高等数学（第七版）上册",
  "layer": "scope",
  "kind": "textbook",
  "trust": "high",
  "coverage": ["第1章", "第2章", "3.1-3.4"],
  "source": "用户上传",
  "path": "materials/gaoshu-7a.pdf",
  "edition": "第七版",
  "year": 2014,
  "applicable_exam": "2026 期中",
  "added_at": "2026-11-07",
  "supersedes": null,
  "notes": "主教材，用户课程指定"
}
```

字段规则：

| 字段 | 取值 | 判定方法 |
| --- | --- | --- |
| `layer` | `scope` / `authority` / `exam` | 问一句「这份资料主要用来定边界、定对错，还是定考法」 |
| `kind` | `textbook` / `supplement` / `syllabus` / `past-paper` / `notes` / `reference` | 按物理形态判，不按用途判 |
| `trust` | `high` / `medium` / `low` | 正式出版且用户指定=high；正式出版但未经用户确认=medium；网传、学长笔记、推断=low |
| `coverage` | 章节或页码数组 | 必须能对应到知识地图的节点，对不上就写 `unmapped` |

一份资料只能有一个 `layer`。如果它同时承担多种用途（例如教材附带的课后题），拆成两条记录，或用 `kind=textbook` + `notes: "含习题"` 说明，不重复入库。

`trust=low` 的资料可以入库，但不能作为裁决依据，讲的时候必须标注来源。

## 3. 优先级矩阵

| 裁决问题 | 第一顺位 | 第二顺位 | 第三顺位 | 不参与 |
| --- | --- | --- | --- | --- |
| 讲什么、讲到哪 | 考纲 | 主教材目录 | 真题覆盖范围 | 教辅、笔记 |
| 什么不考 | 考纲明示排除 | 真题从未出现且教材标选学 | — | 国外教材 |
| 定义与定理是否严谨 | 权威参考（经典教材/论文） | 主教材 | 国内教辅 | 笔记 |
| 考场怎么写 | 主教材记号 | 教师课件/板书 | 真题答案写法 | 国外教材 |
| 考法、题型、分值 | 本校历年真题 | 考纲题型说明 | 同校模拟题 | 外校题 |
| 练什么题 | 主教材例题 | 真题同型题 | 教辅习题 | — |

矩阵的使用方式：先定位问题属于哪一行，再从左往右取第一个可用项。不同行之间不比较，避免"教材和真题谁更重要"这类无解争论。

## 4. 冲突裁决流程

发现两处资料说法不一致时，按顺序做四步：

1. **判类型**：属于范围冲突、正确性冲突、考法冲突，还是纯表述差异。
2. **取裁决源**：按第 3 节矩阵取第一顺位；第一顺位缺失时降一档。
3. **写裁决记录**：追加一条 `CONF`：

```json
{
  "id": "CONF-0031",
  "topic": "极限存在与左右极限",
  "conflict": "教材A称『极限存在当且仅当左右极限相等』，未要求有限值；教材B要求左右极限为有限数",
  "type": "correctness",
  "ruling": "按教材B（权威层）讲定义；考试按教材A写法作答",
  "evidence": ["DOC-0001#p58", "DOC-0004#p12"],
  "created_at": "2026-11-07"
}
```

4. **讲的时候显式提示**：下次讲到该知识点，先给一句"这里两本书说法不同，考试按 X 写，理解按 Y 想"。

裁决记录只增不改。推翻旧裁决时新建一条并写 `supersedes`。

## 5. 缺口检测

每次资料变动后跑一次，输出三类缺口：

**A. 考纲有、教材没讲**
考纲节点集合减去教材 `coverage` 覆盖的节点集合。处理：标 `missing-source`，讲解时用权威层补，并在知识地图标"教材缺口"。

**B. 真题考过、教材没覆盖**
真题考点集合减去教材覆盖集合。处理：优先补讲，因为这是实际得分点。

**C. 教材有、考纲不要求**
教材覆盖集合减去考纲集合。处理：标 `[拓展]`，不进主线，不占复习预算。

检测结果写进 `01-知识地图.md` 的缺口列（`missing-source` / `待补前置` / `[拓展]`），并在 `progress.md` 的"未闭环缺口"里留指针。`02-资料清单.md` 是由 `records/sources.jsonl` 渲染的视图，只放四标，不塞缺口，也不手改。

节点对齐靠 `coverage` 里的章节名匹配知识地图节点。匹配不上时不要猜，列进 `unmapped` 让用户确认。映射率 = 已对齐节点数 ÷ 知识地图节点总数；每次新增资料或改知识地图后重算，记在 `01-知识地图.md` 末尾的「映射率」一行，低于 0.8 先补映射再开讲。

## 6. 增量添加协议

用户中途加资料时：

1. 先问三件事：这是什么（kind）、主要用来干什么（layer）、覆盖哪些章节（coverage）。
2. 入库并打四标，`added_at` 记当天。
3. 只做**增量**：新增覆盖映射、新增缺口，不推翻已有讲解与进度。
4. 若新资料与已有裁决冲突，走第 4 节流程，不静默覆盖。
5. 若新资料替换旧资料（同一本书的新版），新记录写 `supersedes: DOC-0001`，旧记录保留。

不允许的行为：拿到一份资料直接开始讲，跳过标定；或者把教辅当考纲用。

## 7. 降级路径

资料不齐是常态，不能因此停摆。按缺失类型降级：

| 缺什么 | 降级方案 | 标注 |
| --- | --- | --- |
| 无考纲 | 教材目录 + 真题题型反推范围 | `inferred-scope` |
| 无真题 | 教材章末题 + 公开题型分布估计 | `inferred-exam` |
| 无主教材 | 指定一本公开经典教材建骨架，或按用户课程名匹配公开大纲 | `trust=medium` |
| 三者全无 | 先做 20 分钟诊断测评，按错题反推范围，再补资料 | `bootstrap` |

降级产生的范围必须标 `inferred`，且每讲结束时问一句"这个范围和你老师讲的一致吗"，用用户反馈修正。

## 8. 学科包

学科特有的东西放 `subjects/<学科>/`，不写进主循环：

```text
subjects/calculus/
  syllabus.md          默认范围模板（若无用户考纲）
  glossary.md          术语与记号对照
  render.md            公式渲染约定、禁用写法
  exam-patterns.md     常见题型与分值结构
  misconceptions.md    该学科高频误解
```

学科包只能**收窄**，不能**放宽**主循环的硬规则。例如数学学科包可以规定"禁用洛必达"，但不能规定"资料可以不打标签"。

新增学科时只写学科包，不改 SKILL.md。

## 9. 版本与改版

`edition` / `year` / `applicable_exam` 三个字段可选，但同一门课有多版教材时必须填。

改版时按四步：

1. 新资料入库，`supersedes` 指向旧记录，旧记录保留。
2. 对比两版目录，列出新增节点、删除节点、改名节点。用 `python scripts/chapter_diff.py 旧版 新版 --questions 题目.jsonl`：支持 Markdown 标题树、PDF 目录与 `toc.json`，改名按标题相似度识别，并列出页码偏移；带 `--questions` 时把 `textbook_ref` 落在删除/改名章节的题标为 `retired`。
3. 扫描版 PDF 常无内嵌目录：先用 `python scripts/toc_extract.py 教材.pdf --pages 2-4 --out toc.json` 抽印刷目录页（有文本层直读，否则 OCR）。脚本输出 `raw` 原文行与 `suspects`；文本层错位时退出 1，由**模型按 raw 校对并重建 `toc.json`**（标题、章/节层级、页码），不要让用户手抄。重建后再跑 `chapter_diff.py`。
4. 受影响的知识点改标"待补"；旧版才有的题标 `retired`，不删除。
5. 考纲换年份时，先重跑缺口检测，再改 `00-范围与规则.md`，不沿用旧结论。

不做正文全文 diff：页码会整体偏移，逐条人工核对目录与题号更可靠；版本对比只做章节树（`chapter_diff.py`），不做段落级文本比对。

## 10. 隐私与版权

- 教材扫描件、真题、手写作业只在本地使用，不上传、不外发。
- 需要外部检索时，只发必要的题目片段或概念名，不发整页扫描件。
- 引用受版权保护的内容只给短摘与页码，不整段复制。
- 笔记里不写真实姓名、学号、联系方式；需要区分身份用 `student-id` 占位。

## 11. 反模式

- 把「用户说很重要」当成 `trust=high`：口述只能当线索。
- 把教辅的解题技巧当权威层：技巧属于应试层。
- 用外校真题定考法：应试层只认本校。
- 资料一变就重排整个进度：只做增量。
- 缺口不报告，等讲到才发现没资料。
- 同一份资料重复入库、`layer` 每次不同：一份资料一个 `layer`。
