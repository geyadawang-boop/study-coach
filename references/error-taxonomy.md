# 错误归因与复盘

## 五类归因

批改时只选一个主因；主因决定补救动作，次因写进备注。

| 类型 | 识别信号 | 最小修复动作 |
| --- | --- | --- |
| 概念 | 定义条件漏写、定理适用范围错、混淆可导与连续 | 回到定义，用一句话复述成立条件，再做 1 道判断题 |
| 运算 | 符号、系数、链式法则、求导顺序出错 | 同题重算一遍并逐步对照公式，补 1 道纯计算变式 |
| 表述 | 结果对但缺依据、跳步、结论没扣定义 | 按考场书写模板重写，标出每一步依据 |
| 方法选择 | 用了禁用方法、夹逼放缩方向错、等价替换不适用 | 画题型识别信号表，换方法重做，总结"什么时候不能用" |
| 审题 | 看漏条件、定义域、端点、所求对象 | 复述题意并圈出限制条件，再做 1 道同型题 |

## 判定口径

批改先判四类，再归因：

| 判定 | 含义 | 处置 |
| --- | --- | --- |
| 正确 | 过程与结果都对 | 记录通过，不放行"下次再说" |
| 侥幸正确 | 结果对，但关键步骤错、漏条件或蒙对 | 记 `ERR`（`consequence=丢分`），重讲该步并重做 |
| 结果对但缺依据 | 过程跳步、没写条件 | 按表述类处理，补依据 |
| 方法错 | 方法不适用或违规 | 换方法重做，记方法选择类 |
| 未做 | 空题或只写结论 | 先给提示阶梯，不直接给解 |

判"侥幸正确"的三个动作：让用户口述关键步；把题中一个数换掉重算；若原解在新数下失效，就是蒙对。

## 归因问句

依次问，答不上来就停在那一步：

1. 这题在问什么？所求量的定义是什么？
2. 我用的方法需要什么条件？题目满足吗？
3. 每一步的依据是什么？哪一步是"显然"带过的？
4. 结果能验算吗？端点、符号、量纲对吗？
5. 如果题目改一个条件，方法还成立吗？

## 常见错误模式

- 减法结构直接等价替换，导致主项抵消成 0：先因式分解，或用高阶等价表。
- `arctan x - x` 的等价无穷小系数为负（`-x³/3`），符号易错。
- ε-δ 证明漏写 `0 < |x - x₀| < δ`，或分母放缩没给理由。
- 1^∞ 型极限直接把底数等价替换，没有先做 `(底数 - 1)` 变形。
- 和式极限对每一项单独等价替换：和式不能逐项替换，改用夹逼或定积分定义。
- 参数方程二阶导数写成 `d²y/dx² = (d/dt)(dy/dx)`，漏除 `dx/dt`。
- 分段点可导性只验证左右导数相等，漏验证连续性；连续是可导的必要条件。
- 高阶导数用 Leibniz 公式时二项式系数或低阶导数为零的项处理错。

## 错误模拟（出题前）

出模拟题或干扰项前，先按五类各写 1 条"学生可能怎么错"，再决定题面：

| 字段 | 写法 |
| --- | --- |
| 错误做法 | 具体动作，不写"粗心" |
| 触发条件 | 什么样的题面会诱发 |
| 错误结果 | 会算出什么，错在哪一步 |
| 对应错因 | 概念/运算/表述/方法选择/审题 |

用途：客观题据此设干扰项，解答题据此设陷阱。错误路径只用于设计题目和复盘，不写进主线讲解，避免把错误做法教给用户。

## 变式生成与偏离检查

变式不是自由出题，按四步做：

1. 抽母题骨架：已知、所求、关键步骤、每一步的使用条件。
2. 定槽位：数值、符号、图形位置、参数范围；每个槽位写合法域。
3. 只换槽位，锁定考点、骨架与难度档。
4. 偏离检查，任一项为"是"就拒绝生成并说明原因：
   - 换了新知识点？
   - 某步使用条件不再满足？
   - 步骤数变化超过 1 步？
   - 难度跨档？
   - 找不到可回指的母题？

生成后先自己完整做一遍，用 `scripts/step_check.py` 验算关键步，再交给用户。

## 对比式评分

评分固定四步，单遍完成，不做多模型互评或辩论：

1. 先列 rubric：得分点、每点分值、关键依据。
2. 读学生解，标出每一步对应哪个得分点。
3. 学生解与参考答案逐点对比，判"正确/缺依据/错/未做"。
4. 给判定、主因与一个最小修复动作。

同一解答重复评分时沿用同一 rubric；两次差异超过 1 个得分点就重判，不取平均。

## 复盘输出

每次批改写四行：

```text
判定：正确 / 结果对过程缺依据 / 方法错 / 未做
主因：概念 / 运算 / 表述 / 方法选择 / 审题
修复：一个最小动作
变式：一道同型题（当场做）
```

同一主因连续出现 2 次，升级为专项：补讲 + 3 道变式 + 隔天回测。
