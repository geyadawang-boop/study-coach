# 输出契约与渲染

## 对话输出（聊天窗）

聊天窗按 CommonMark 渲染，**不解析 LaTeX 的 `$` 行内公式和 `$$` 独立公式**。同一份数学内容分两种写法：

| 场景 | 写法 |
| --- | --- |
| 对话回复 | 不用 LaTeX；简单符号用 Unicode，分数用 `/`，分段/多行放 text 代码块 |
| `notes/*.md` | 用 `$...$` / `$$...$$`（Obsidian、飞书支持） |

对话里的替换规则：

- `\pi` → π，`\le` → ≤，`\ge` → ≥，`\ne` → ≠，`\to` → →，`\infty` → ∞，`\sqrt{x}` → √x。
- `x^{2}` → x²，`x_{n+1}` → xₙ₊₁，`\frac{a}{b}` → `a/b` 或 `(a)/(b)`。
- `\sin`、`\cos`、`\arcsin`、`\ln` 直接写函数名，不加反斜杠。
- 分段函数写成对齐的 text 代码块，不写 `\begin{cases}`。
- 必须给 LaTeX 源码时，先写「LaTeX 源码如下」，放进代码块，再给一个 Unicode 可读版；不要在一句话里混半截 `$...$`。

对话版示例：

    f(x) = x,        0 ≤ x ≤ π/2
           π − x,    π/2 ≤ x ≤ 3π/2
           x − 2π,   3π/2 ≤ x ≤ 2π

## 讲解版

用于讲知识点、讲真题。结构固定七段：

```text
【题目】完整题面；OCR 来源先校对
【定性】这题在考什么信号；第一步；与哪道旧题像但哪里不同
【解答】分步，每步写依据
【考场写法】可直接抄到答题卡的版本
【验算/边界】特殊值、端点、量纲；有歧义写两种理解
【易错点】3–6 条：错误写法 → 正确写法 → 后果；必要时加同类题对比表
【一句话】识别信号 + 第一步
```

## 追问版

用于用户追问「为什么可以这样」「这个记号什么意思」。结构固定：

```text
【问题】复述用户卡住的那一步或那个记号
【一句话】先给结论，不重抄首讲
【视角 1..n】至少两种：定义 / 图像 / 换元 / 反函数 / 标准公式
【数值验证】表：取 2–3 个点，两条路算给用户看
【对比表】易混记号、同类题、不同主值区间
【一句话】把「为什么」压成一句可复述的话
```

结构检查：`scripts/explain_lint.py --level solution|followup`；缺段或深度不足退出 1。

## 多解版

用户要「更优解」「一题多解」，或题目有两种以上主流方法时：

```text
【题目】完整题面
【常规解法】步骤完整，排第一；答题卡默认写它
【多解对比】表：解法 / 关键步骤 / 适用 / 考场耗时 / 风险 / 验算
【验算】特殊值表或 step_check 结果
【来源】URL + 访问日期；没联网写「未外部检索」
【一句话】考场上先写哪种，什么时候换
```

替代解法最多两种；每种都要能复现、能验算、有失效条件。检索协议与降级规则见 `references/solution-research.md`。

结构检查：`scripts/explain_lint.py --level multi`；缺常规解法、对比表、验算或来源退出 1。

## 批改版

用于用户提交解答后：

```text
【判定】正确 / 结果对过程缺依据 / 方法错 / 未做
【得分点】逐点给分或指出缺失
【主因】概念 / 运算 / 表述 / 方法选择 / 审题
【修复】一个最小动作
【变式】一道同型题
```

## 可提交版

用户要交作业时：

- 只给题目与解答，不加讲解、不加表情、不加鼓励语。
- 解答用规范符号，关键步骤不跳步。
- 多题按题号顺序排列，一题一段。
- 用户要求"对话内展示"时不要生成文件；要求图片时再导出。

## 笔记文件头

`notes/*.md` 统一用 YAML frontmatter，缺字段不算成稿：

```yaml
---
id: LEC-003
type: lecture | paper | review
chapter: 第2章
concepts: ["无穷小比较"]
source: ["DOC-0001#p58", "TP-2024A#3"]
status: draft | taught | verified
confidence: high | medium | low
labels: [考点, 陷阱]
created: 2026-11-07
---
```

`source` 必须能回指资料 ID 与页码；`confidence` 指这份笔记的依据强度，不是用户掌握度。

## 六类标注

正文用行内标签，固定六个词：

| 标签 | 含义 | 处置 |
| --- | --- | --- |
| 考点 | 考纲要求、真题考过 | 进主线与复习队列 |
| 难点 | 需要多步或需要构造 | 讲慢，配渐隐练习 |
| 陷阱 | 常见错法、易漏条件 | 进易错点汇总 |
| 超纲 | 教材有但考纲不要求 | 行内写 `[拓展]`，不进主线 |
| 待核 | 来源不可靠或识别不确定 | 回问用户或核原文，不带疑问下结论 |
| 自编 | 自己出的题或例子 | 标明自编，不冒充真题 |

## 引用与忠实性

- 每个引用写成 `DOC-0001#p58` 或 `URL（访问 2026-11-07）`。
- 引用必须真的支持这句话；只支持一部分就缩窄表述，指不到就删。
- 不引用没打开过的资料；不把"报告里说"当成"我核过"。
- 资料原文与自己的推论分开写，推论标「推断」。
- 引用与结论冲突时，先改结论，不硬留引用。

## 交付前自检

给出"正确"结论前过三关，任一不过就回头：

1. **符号**：能验算的用 `scripts/step_check.py` 逐步验；未验的标 `[未验]`。
2. **特殊值**：代入 0、1、边界值或极端值；结果明显不符就重算。
3. **端点与量纲**：检查定义域、端点、单位与量纲。

`step_check.py` 只验代数等价与极限，不检查定义域；定义域必须人工看。

## 公式渲染

以上公式写法只适用于 `notes/*.md` 等支持 LaTeX 的文件；对话回复按「对话输出（聊天窗）」写 Unicode。

- 禁止 `\left| ... \right|`：改用 `\lvert ... \rvert` 或直接写 `| ... |` 的简单形式。
- 禁止 `\mathbb{Z}` 等黑板体：改用 `\mathbf{Z}` 或文字"整数集"。
- 表格单元格内避免裸 `|`：绝对值写成 `\lvert x \rvert`，或把该列移出表格。
- 长公式独立成行，不塞进列表项或表格。
- 上下标含多字符时加花括号：`e^{x}`、`x_{n+1}`。
- 同一题内符号统一：不要一半用 `y'` 一半用 `\frac{dy}{dx}`。

## 语言

- 中文讲解，术语保留英文缩写时可加中文注释。
- 不写"显然""易得"带过关键步骤；需要时补一句依据。
- 不确定的结论标注"待核"，不编造真题年份、分值或题号。
