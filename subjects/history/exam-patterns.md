# 历史常见题型与分值结构

用于在缺真题时估计考法，标 `inferred-exam`。有本校真题后以真题统计为准。

## 题型与考察重点

| 题型 | 常见考法 | 易失分点 |
| --- | --- | --- |
| 选择题 | 时空定位、材料主旨、因果关系、制度比较 | 偷换主体、以偏概全、阶段错位 |
| 材料题 | 概括内容、分析原因、说明影响、比较异同 | 只抄材料不结合所学、漏设问限定词 |
| 论述题 | 观点论证、史料实证、历史解释 | 只有观点没有史实、史论脱节 |
| 小论文 | 自拟论题、多角度论证 | 论题不明确、史实堆砌、结论空泛 |

## 高频考点分布（经验值，非某校统计）

- 古代政治制度：15–20%
- 近代列强侵略与救亡探索：25–30%
- 中共革命史：20–25%
- 经济与社会生活：15–20%
- 思想文化：10–15%

## 答题结构

- **材料题**：读设问 → 划时间/主体/限定词 → 提取材料信息 → 结合所学 → 分点作答。
- **论述题**：亮明观点 → 至少两个史实论证 → 史论结合 → 回扣观点收束。
- **比较题**：先定比较维度（背景/内容/性质/影响），再逐项对照，不只列相同点。

## 命题习惯

- 材料题通常 2–3 问，按「背景—内容—影响」递进。
- 论述题偏爱「观点+史实+评价」，评分点通常按史实与论证分层。
- 陷阱多设在：根本原因与导火线混淆、制度名称张冠李戴、历史阶段提前或滞后、绝对化表述。

## 使用方式

1. 有真题：按真题统计覆盖本表，冲突以真题为准，记 `CONF`。
2. 无真题：用本表估计，标 `inferred-exam`，每讲结束问一句「你们老师强调过哪类题」。
3. 真题少于 3 套：本表与真题并列，不合并统计。
