# 历史验证策略

本文件只约束 history 学科包。主循环不写死数学规则，遇到验证与论述都回到这里。
`explain_lint.py --subject history` 会读上面的 `verify: evidence`，要求验证段带证据/评分点表格。

## 结论怎么验

1. **史料对应**：每个结论至少给一条材料出处或教材页码（章节 + 页码），不能只给观点。
2. **时空定位**：写清事件的时间、地点、主体；朝代与阶段不能混用。
3. **因果链**：区分根本原因、直接原因与导火线；材料题先划设问限定词（背景/内容/影响/评价）。
4. **评分点核对**：按「结论 / 证据 / 对应评分点」列成表格，逐条自查；缺证据的结论标 `[未验]`。

## 追问的三层

- 一句话结论。
- 两种视角：制度/经济视角与史料/史学视角，并给证据核对表。
- 概念拆解：区分易混制度、事件性质与历史阶段。

## 多解怎么核

- 常规解释排第一且必须完整。
- 替代解释要说明史料依据与适用边界（如革命史观 / 现代化史观），不能只换措辞。
- 多种解释结论不一致时给对比表：核心主张、证据、适用题型、风险。

## 什么时候标未验

- 没有材料出处或教材页码 → 标 `[未验]`，不判正确。
- 材料缺失导致主体、时间或因果无法确认 → 先索取材料，不猜。
