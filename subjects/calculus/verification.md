# 微积分验证策略

本文件只约束 calculus 学科包。主循环不写死数学规则，遇到验证与多解都回到这里。

## 结论怎么验

1. **逐步等价**：用 `scripts/step_check.py` 检查每一步变形；不等价时指出首个断点，不整段重写。
2. **符号验算**：装了 SymPy 时对极限、导数、积分做符号核对（`step_check.py` 自动走 SymPy 分支）。
3. **数值抽检**：至少取两个特殊值或边界值代入原式与结果（避开奇点）；数值不符直接判错。
4. **条件与定义域**：先写适用条件（如 x→0、分母非零、根号内非负），再谈结论；条件缺失就标 `[未验]`。

## 追问的三层

- 一句话结论。
- 两种视角：代数变形 / 几何或泰勒展开，并给数值验证。
- 记号与定义拆解：写清每个符号的含义与边界。

## 多解怎么核

- 常规解法排第一且必须完整。
- 每种替代解法过 `step_check.py` 或特殊值验算，并写清适用与失效条件。
- 多解结论一致时给对比表：步骤数、易错点、考场耗时。

## 什么时候标未验

- 未装 SymPy 且无法数值抽检 → 标 `[未验]`，不判正确。
- 题目条件缺失导致定义域或可导性无法确认 → 先索取条件，不猜。
