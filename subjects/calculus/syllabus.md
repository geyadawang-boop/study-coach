# 微积分默认范围模板

仅在用户未提供考纲时使用，标 `inferred-scope`。用户提供考纲后以考纲为准，本文件降为参考。

## 单变量微积分（一学期）

| 模块 | 必讲 | 通常选学 |
| --- | --- | --- |
| 函数与极限 | 极限定义、四则与复合、两个重要极限、无穷小比较、连续性、间断点分类 | 确界原理、实数完备性 |
| 导数 | 定义、求导法则、高阶导、隐函数、参数方程、微分 | 曲率 |
| 微分中值定理 | 罗尔、拉格朗日、柯西、泰勒、洛必达、单调与极值、凹凸与拐点、渐近线 | 达布定理 |
| 不定积分 | 基本表、换元、分部、有理函数积分 | 欧拉代换 |
| 定积分 | 定义、性质、微积分基本定理、换元与分部、反常积分 | 定积分近似计算 |
| 应用 | 面积、体积、弧长、物理应用 | 经济应用 |

## 多变量微积分（一学期）

| 模块 | 必讲 |
| --- | --- |
| 空间解析几何 | 向量、平面与直线、曲面与曲线 |
| 偏导与全微分 | 偏导、全微分、复合函数求导、隐函数求导 |
| 极值与应用 | 无条件极值、条件极值（拉格朗日乘数）、几何应用 |
| 重积分 | 二重积分、三重积分、极坐标与柱/球坐标、交换积分次序 |
| 曲线与曲面积分 | 第一/二类曲线积分、第一/二类曲面积分、格林、高斯、斯托克斯 |

## 范围裁剪规则

- 考纲明示排除的模块整块跳过，在知识地图标 `excluded`。
- 考试分值占比低于 5% 的模块，降到「了解 + 会套公式」。
- 真题从未出现且教材标选学的，标 `[拓展]`，不进主线。
- 用户课程使用非标准教材时，用其目录覆盖本表，本表只作缺口检查对照。
