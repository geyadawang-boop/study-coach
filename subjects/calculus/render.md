# 公式渲染约定

## 对话回复 vs 笔记文件

| 场景 | 渲染器 | 公式写法 |
| --- | --- | --- |
| 对话回复 | CommonMark，不解析 LaTeX | 不用 LaTeX；简单符号用 Unicode，分数用 `/`，分段/多行用 text 代码块 |
| `notes/*.md` | Obsidian / 飞书，支持 LaTeX | 按下面的行内/独立公式规则 |
| HTML/PDF 导出 | 浏览器（启用 KaTeX/MathJax 时） | 可用 LaTeX；导出后实际打开检查 |

对话里必须给 LaTeX 时，先写「LaTeX 源码如下」并放进代码块，同时给 Unicode 可读版。

常用替换：`\pi`→π，`\le`→≤，`\ge`→≥，`\to`→→，`\infty`→∞，`\sqrt{x}`→√x，`x^{2}`→x²，`x_{n+1}`→xₙ₊₁，`\frac{a}{b}`→a/b 或 (a)/(b)。

以下「禁用写法」「书写规范」只适用于笔记文件。

## 禁用写法

| 禁用 | 原因 | 改用 |
| --- | --- | --- |
| `\left| ... \right|` | 部分渲染器把 `|` 当表格分隔符 | `\lvert ... \rvert` |
| `\mathbb{Z}` | 部分字体缺 Blackboard 字形 | `\mathbf{Z}` 或直接写「整数集」 |
| `\dfrac` 嵌套在行内 | 行高溢出 | 行内用 `\frac`，独立行用 `$$...$$` |
| 中文放进 `$...$` | 渲染失败 | 中文移到公式外 |

## 书写规范

- 行内公式用 `$...$`，独立公式用 `$$...$$` 单独成行，前后留空行。
- 多行推导用 `aligned`，等号对齐。
- 极限写 `\lim_{x \to a}`，不写 `\lim_{x \rightarrow a}`（语义相同，统一风格）。
- 积分写 `\int_{a}^{b} f(x)\,\mathrm{d}x`，微分符号前加 `\,`。
- 导数用 `f'(x)` 或 `\frac{\mathrm{d}y}{\mathrm{d}x}`，同一篇内不混用。
- 向量用 `\mathbf{v}`，不用箭头（部分渲染器箭头错位）。

## 考场写法对齐

讲解时给两套：

1. **理解版**：步骤完整、每步有理由。
2. **考场版**：省略显然步骤，保留得分点，控制篇幅。

两套必须结论一致。考场版省略的步骤要说明「考场上可略，因为评分细则不设点」。
