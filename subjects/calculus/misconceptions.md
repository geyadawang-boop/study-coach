# 微积分高频误解库

按「误解 → 表现 → 探测题 → 纠正话术」组织。新增误解用 `ERR`/`CONF` 记录，定期回填本文件。

## M-01 极限存在 = 左右极限相等

- **表现**：忽略「有限」要求；或认为趋于无穷时极限存在。
- **探测**：判断 $f(x)=1/x$ 在 $x\to 0$ 时极限是否存在。
- **纠正**：极限存在要求左右极限存在、相等且为有限数。

## M-02 可导必连续，连续必可导

- **表现**：把两个方向的蕴含关系弄反。
- **探测**：$f(x)=\lvert x\rvert$ 在 0 处是否可导。
- **纠正**：可导 ⇒ 连续；连续 ⇏ 可导。用尖点反例。

## M-03 洛必达适用条件忽略

- **表现**：非未定式也用；用完不验极限存在。
- **探测**：$\lim_{x\to 0}\frac{x+\sin x}{x}$ 能否直接用洛必达。
- **纠正**：先验 $0/0$ 或 $\infty/\infty$，再验求导后极限存在。

## M-04 换元忘换积分限

- **表现**：换元后仍用原变量上下限。
- **探测**：$\int_0^1 2x e^{x^2}\mathrm{d}x$，令 $u=x^2$。
- **纠正**：换元同时换限；或换回原变量再代限。

## M-05 定积分与面积混同

- **表现**：认为积分值一定非负。
- **探测**：$\int_{-1}^{1} x\,\mathrm{d}x$ 与对应面积。
- **纠正**：定积分是代数和，面积取绝对值。

## M-06 条件极值忽略边界

- **表现**：只解拉格朗日方程，不检查约束边界与退化点。
- **探测**：求 $x^2+y^2$ 在 $x+y=1$ 上的最值。
- **纠正**：先看约束集是否紧，再判驻点与边界。

## M-07 无穷小比较阶数算错

- **表现**：把 $1-\cos x$ 当一阶。
- **探测**：$x\to 0$ 时 $1-\cos x$ 是 $x$ 的几阶无穷小。
- **纠正**：记住 $1-\cos x \sim x^2/2$，用泰勒统一判断。

## M-08 级数收敛必要条件的误用

- **表现**：由通项趋于 0 断言级数收敛。
- **探测**：$\sum 1/n$ 通项趋于 0，是否收敛。
- **纠正**：通项趋于 0 是必要条件，不是充分条件。

## M-09 反三角套三角直接抵消

- **表现**：把 $\arcsin(\sin x)=x$、$\arccos(\cos x)=x$ 当成恒等式。
- **探测**：写出 $\arcsin(\sin x)$ 与 $\arccos(\cos x)$ 在 $[0,2\pi]$ 上的表达式。
- **纠正**：反三角只返回主值区间；$\arcsin$ 的主值是 $[-\pi/2,\pi/2]$，$\arccos$ 是 $[0,\pi]$，超出就折返。$\sin(\arcsin x)=x$ 与 $\arcsin(\sin x)=x$ 的成立范围不同。
